# **App Name**: ResumeCraft

## Core Features:

- Profile Input: User-friendly interface for entering personal information.
- Experience Input: Structured input fields for work experience details.
- Education Input: Dedicated sections for detailing education history.
- Template Selection: Option to select from pre-designed resume templates.
- Resume Enhancement: AI-powered tool suggesting improvements to wording and formatting, using insights from resume best practices.
- PDF Export: Generates a downloadable PDF version of the resume.
- Live Preview: Live preview of the resume as it's being built.

## Style Guidelines:

- Primary color: Light gray (#D3D3D3) for a clean background.
- Background color: White (#FFFFFF) for a professional appearance.
- Accent color: Dark gray (#4A4A4A) for text and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look.
- Minimalist layout with clear sections for each resume component.
- Simple, professional icons for contact information.
